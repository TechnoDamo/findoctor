# Тестовые сценарии БД

Команды запускаются из папки `db`:

```bash
make test-users-create
make test-users-list
make test-users-delete
make test-users-reset
```

Пароль для всех пяти пользователей: `TestPassword123!`.

Фикстура создаёт пять больших и разных сценариев:

- `scenario.alexei.stability@findoctor.test` — стабильная высокая зарплата, резерв, брокерский счёт, почти нет долгов.
- `scenario.irina.freelance@findoctor.test` — нерегулярный фриланс-доход, налоговая задолженность, кассовые разрывы, рабочие расходы.
- `scenario.pavel.debt-recovery@findoctor.test` — восстановление после просрочек, кредитная карта, автокредит, маленький резерв.
- `scenario.elena.family-mortgage@findoctor.test` — семейный бюджет, ипотека, дети, ремонт, высокая доля обязательных расходов.
- `scenario.nikolai.retirement@findoctor.test` — пенсия, аренда, дивидендный портфель, медицинские расходы, сохранение капитала.

Данных стало существенно больше: генератор создаёт историю за 72 месяца, то есть примерно в 6 раз больше операций и снимков, чем первая версия фикстуры. Внутри есть пользователи, счета, активы, обязательства, регулярные операции, переводы, сгенерированная история транзакций, платежи по долгам, теги, ежедневные финансовые снимки, банки, мерчанты и длинные записи с историями для AI-чата.
