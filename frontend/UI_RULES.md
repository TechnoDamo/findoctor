# UI_RULES.md

## Проект

PWA финансового помощника на Next.js.

Основной дизайн уже реализован.

Новые страницы должны встраиваться в существующую дизайн-систему, а не создавать новую.

---

# Главный принцип

SVG является главным источником истины.

При конфликте между:

* SVG
* существующим компонентом
* существующим CSS

приоритет всегда у SVG.

Запрещено изменять SVG-макет ради переиспользования компонента.

---

# Использование существующего проекта

Перед созданием новой страницы необходимо изучить:

* FinanceHeader
* BottomSheetModal
* finance.module.css
* существующие иконки
* существующие анимации

Переиспользовать их, если это не ломает SVG.

---

# Mobile First

Базовый экран:

```text
402 x 874
```

Сначала добиться визуального совпадения на базовом размере.

Только после этого делать адаптацию.

Поддерживаемые размеры:

```text
360
375
390
402
414
430
```

---

# Интерактивность

## Button

Использовать только если элемент:

* открывает модалку;
* открывает страницу;
* запускает действие;
* сохраняет данные;
* удаляет данные;
* отправляет форму.

Примеры:

* назад;
* плюс;
* продолжить в чате;
* сохранить;
* удалить.

---

## Не использовать Button

Для элементов, которые ничего не делают.

Использовать:

```html
div
section
article
```

Примеры:

* рекомендации;
* статистика;
* финансовые показатели;
* информационные карточки;
* текстовые блоки;
* прогресс без действия.

---

# Cursor

Разрешено:

```css
cursor: pointer;
```

только на интерактивных элементах.

Запрещено:

```css
cursor: pointer;
```

на информационных карточках.

---

# Анимации

## Разрешено

Использовать существующие анимации проекта:

* press animation;
* button animation;
* modal animation.

---

## Запрещено

Добавлять press animation элементам без действия.

Если у элемента нет:

```tsx
onClick
href
openModal
```

то у него не должно быть:

```css
:active
cursor:pointer
scale
press effect
```

---

# Модальные окна

Все модалки должны использовать:

```tsx
BottomSheetModal
```

Не создавать собственные реализации модалок.

Не создавать popup через absolute/fixed вручную.

---

# Header

Для новых страниц использовать:

```tsx
FinanceHeader
```

Не создавать отдельную реализацию шапки.

---

# SVG Layout Rules

Запрещено изменять:

* размеры блоков;
* позиции блоков;
* радиусы;
* размеры текста;
* цвета;
* расстояния между элементами.

Допускается только адаптация под ширину экрана.

---

# Scroll

Если высота SVG больше viewport:

использовать:

```css
overflow-y: auto;
```

Страница должна скроллиться естественно.

Запрещено:

```css
height: 100vh;
overflow: hidden;
```

для длинных экранов.

---

# Цвета

Использовать существующие цвета проекта.

Если цвет отличается от SVG более чем визуально заметно:

создать отдельную CSS-переменную.

Не подбирать цвет "на глаз".

---

# Типографика

Шрифт:

```text
Montserrat
```

Использовать существующие размеры из проекта.

Если SVG требует другой размер — использовать размер из SVG.

---

# CSS

Предпочтительно:

```text
PageName.module.css
```

Не добавлять уникальные стили страницы в:

```text
globals.css
finance.module.css
```

если стиль используется только одной страницей.

---

# Перед завершением страницы

Проверить:

1. Все ли кнопки действительно выполняют действие.
2. Нет ли button без действия.
3. Нет ли cursor:pointer на информационных блоках.
4. Нет ли анимации на информационных блоках.
5. Работает ли scroll.
6. Не перекрываются ли элементы.
7. Совпадает ли страница с SVG.
8. Используется ли FinanceHeader.
9. Используется ли BottomSheetModal для модалок.
10. Не были ли изменены существующие компоненты ради новой страницы.

Если хотя бы один пункт не выполнен — страница считается незавершенной.
