# UI_RULES.md

## Цель

Все новые страницы должны визуально соответствовать SVG-макетам и одновременно использовать существующую дизайн-систему проекта.

SVG является главным источником истины по визуалу.

---

# Иерархия источников

При конфликте:

1. SVG-макет
2. Design Spec
3. Существующие компоненты
4. Общие CSS-классы
5. Предположения разработчика

Запрещено изменять макет ради переиспользования существующего компонента.

---

# Интерактивность

## Разрешено использовать button

Только если элемент:

* открывает модалку;
* открывает bottom sheet;
* выполняет действие;
* отправляет форму;
* изменяет данные;
* переводит пользователя на другой экран.

Примеры:

* кнопка назад;
* кнопка "+";
* "Продолжить в чате";
* карточка открытия модалки;
* кнопка сохранения;
* кнопка удаления.

---

## Запрещено использовать button

Для информационных блоков.

Примеры:

* рекомендации;
* статистика;
* финансовые показатели;
* суммы;
* текстовые карточки;
* декоративные блоки;
* прогресс без действия.

Использовать:

```html
div
section
article
```

---

# Анимации

## Можно использовать press-animation

Только на интерактивных элементах.

Примеры:

* CTA-кнопки;
* кнопки открытия модалки;
* навигационные элементы.

---

## Нельзя использовать press-animation

На:

* карточках рекомендаций;
* карточках статистики;
* информационных блоках;
* элементах без onClick.

---

# Cursor

Разрешено:

```css
cursor: pointer;
```

только для интерактивных элементов.

Запрещено:

```css
cursor: pointer;
```

для информационных карточек.

---

# Hover

Мобильное приложение.

Не добавлять hover-эффекты без необходимости.

Допускается только для уже существующих компонентов дизайн-системы.

---

# Layout

Все страницы строятся Mobile First.

Базовый экран:

```text
402 x 874
```

Сначала добиться совпадения на базовом размере.

Только потом адаптация.

---

# Responsive

Поддерживаемые ширины:

```text
360px
375px
390px
402px
414px
430px
```

Запрещено менять структуру страницы ради адаптива.

Адаптив должен только масштабировать отступы и ширины.

---

# Переиспользование компонентов

Разрешено использовать:

* FinanceHeader
* BottomSheetModal
* LogoutButton
* существующие иконки
* существующие анимации кнопок

---

# Когда нельзя переиспользовать компонент

Если компонент меняет:

* размеры из SVG;
* padding;
* margin;
* radius;
* поведение;
* интерактивность.

В таком случае создать новый компонент.

---

# SVG правила

SVG — это layout contract.

Не изменять:

* размеры блоков;
* положение блоков;
* радиусы;
* цвета;
* размеры текста;
* расстояния между элементами.

---

# Модальные окна

Если элемент открывает модальное окно:

Использовать:

```tsx
BottomSheetModal
```

Не создавать отдельную реализацию модалки.

---

# Проверка перед завершением

Перед завершением страницы проверить:

1. Все ли кнопки действительно выполняют действие.
2. Нет ли button без действия.
3. Нет ли cursor:pointer на информационных карточках.
4. Нет ли press-animation на информационных карточках.
5. Совпадает ли layout со SVG.
6. Не перекрывают ли элементы друг друга.
7. Работает ли scroll на длинных страницах.
8. Не сломан ли safe-area для iPhone.

Если хотя бы один пункт не выполнен — страница считается незавершенной.
