# Smoke-Документ RAG ФинДоктора

Это локальный smoke-test документ для recommendation RAG service ФинДоктора.

Для персональных финансовых рекомендаций ассистент должен учитывать финансовую подушку, ежемесячный денежный поток, обязательства, регулярные платежи и цели пользователя перед рекомендацией нового долга или крупной покупки.

Recommendation engine должен ссылаться на retrieved evidence и отделять внутренние финансовые факты пользователя от внешних образовательных материалов.
