# RouterAI Voice Test

Local browser tool for testing RouterAI TTS and STT models.

## Start or Restart

From this folder:

```bash
cd /Users/damir/Documents/ПрофИИт/voice-test
export ROUTERAI_API_KEY="sk-gY63dt1jGYJUvi19vPH9HVT9cVtQRKGo"
node routerai_recorder_server.js
```

Then open:

```text
http://localhost:8787
```

If port `8787` is already busy, find and stop the old process:

```bash
lsof -nP -iTCP:8787 -sTCP:LISTEN
kill <PID>
```

Then run the server again.

## Folders

- `request_audio/` - audio sent into STT requests.
- `response_audio/` - TTS audio generated by models.
- `routerai_outputs/` - JSON responses and SSE logs.

## Model List

Edit `routerai_models.json` to change the models and voices shown in the UI.

## Curl Tests

The curl smoke-test script uses the same model JSON:

```bash
export ROUTERAI_API_KEY="sk-..."
./routerai_audio_curl_tests.sh list
./routerai_audio_curl_tests.sh tts
./routerai_audio_curl_tests.sh stt
```

By default STT curl tests read:

```text
request_audio/test-audio.wav
```
